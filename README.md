# Multiverse Pinball

A roguelike pinball game in a single HTML file: draft superhero-inspired upgrades, build synergies, evolve the machine, collect Infinity Stones and survive villain bosses across a 20-level run (plus endless mode).

**Play:** https://ednen.github.io/multiverse-pinball/

## Controls
| | Keyboard | Touch |
|---|---|---|
| Left flipper | `Z` or `←` | ◀ Flip button, or tap the left half of the table |
| Right flipper | `/` or `→` | Flip ▶ button, or tap the right half |
| Launch | hold `Space`, release | hold **Launch**, release |
| Pause | `P` | |
| The Snap (6 stones) | `G` | Snap button |

## Features
- Custom 2D pinball physics with ramps, a tunnel, orbits, drop targets, a quantum pit and a wormhole
- 100+ upgrade cards across five rarities, with tags and tiered upgrades
- 40+ synergies: card pairs, tag sets, cross-tag combos, character sets and legendary combos
- Machine evolutions that re-theme the table
- Infinity Stones with collection bonuses
- Interactive bosses: Loki, Ultron, Magneto and Thanos
- Shop

## Run locally
Download `index.html` and open it in any browser. No build step and no dependencies.
